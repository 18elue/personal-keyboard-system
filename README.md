# Personal Keyboard System

为 macOS 建立可扩展的跨应用快捷键体系，首批覆盖 VS Code、Chrome、Obsidian。

**Same Intent, Same Shortcut：同一操作意图，尽可能使用同一快捷键。**

## 设计基础

以 macOS 约定为基础，按意图建立跨应用规则，并为高频操作和 App 专属能力保留例外。

完整规则维护在[设计原则](docs/design-principles.md)，包括意图定义、作用层级、按键语义、冲突取舍和扩展方法；跨应用概览维护在[对照表](docs/shortcut-map.md)，正文编辑的详细目标与应用方法维护在[文本编辑统一方案](docs/text-editing.md)。

## 如何使用

从[意图与快捷键对照表](docs/shortcut-map.md)查看官方默认值、统一候选及例外。表中的默认值是官方资料核对记录，不能代替本机现状。

新增 App 或操作时，先依照[设计原则中的扩展方法](docs/design-principles.md#新增一个操作时怎么决定)判断意图和键位，再补入对照表。

落地时每次只调整一个意图，记录原绑定，检查冲突，实际使用后再决定是否保留；配置文件纳入仓库后，以配置为准，文档只解释目的和例外。
